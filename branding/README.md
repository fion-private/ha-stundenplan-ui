# Branding assets

These are the exact same icon assets used by the companion
[`ha-stundenplan`](https://github.com/fion-private/ha-stundenplan) integration
repository, kept visually consistent across both projects: `mdi:school-outline`
rendered in blue (`#1976D2`), directly from the official MDI path data (icon
code `F1180`).

## Where they're used

- `icon.png` / `icon@2x.png`: displayed in this README and (once submitted)
  as the frontend resource's icon.
- `logo.png` / `logo@2x.png`: identical to the icon files - there is no
  separate wordmark for this project.

## Note on HACS/frontend branding

Unlike the integration repository, `home-assistant/brands` only covers
`core_integrations` and `custom_integrations` - there is no equivalent brand
registry entry for standalone Lovelace card ("plugin") repositories. HACS
lists frontend plugins without a dedicated brand icon, so these assets are
primarily used for this README and for consistency with the integration's
branding, not for a specific HACS store icon.
